TorAlza — ключи для скриптов Delta

Минималистичный, но мощный инструментарий, который помогает разработчикам Delta Roblox выпускать скрипты с обязательной активацией через ключ.

Генерация ключей

Создавайте ключи в формате tor-alzaXXXXXXXXXXXX с мгновенной копией в буфер обмена. Такие ключи затем указываются пользователем при первом запуске скрипта.

История текущей сессии

    Проверка ключей

    Вставьте ключ, чтобы убедиться, что он соответствует стандарту Tor Alza и готов к публикации в вашем скрипте.

    Публикация скрипта

    Зарегистрируйте свой скрипт, чтобы связать репозиторий, ключи и автоматическую активацию для пользователей Delta.

    • Используйте отдельный ключ для QA, чтобы проверить активацию перед релизом.
    • Добавьте GitHub Actions, который генерирует ключ и сохраняет его как секрет, чтобы автоматически рассылать его при релизе.
    • Вебхук необязателен: если не указать URL, пользователи смогут активироваться через публичное API TorAlza.

    Платформа для разработчиков

    Создано для команд, которые хотят автоматизировать выдачу ключей, привязку к репозиторию и проверку ключа внутри скрипта Delta.

    CI/CD интеграция

    Подключите генерацию ключей в GitHub Actions или другом CI. Используйте CLI-сниппет ниже, чтобы выпускать ключ при каждом релизе.

    curl -sSL https://tor-alza.dev/cli | bash
export TOR_ALZA_TOKEN=<secret>
tor-alza key create --notes "Release $GITHUB_REF"

    API для проверки

    Стандартизированное REST API позволяет проверить ключ перед активацией скрипта. Используйте /v1/keys/verify с вашим секретом.

    POST https://api.tor-alza.dev/v1/keys/verify
Authorization: Bearer <secret>
{
  "key": "tor-alzaSk3isJ3ns92nzkE2jaE2ndO",
  "resource": "github:username/project"
}

    Проверка скриптов

    Разместите скрипт в GitHub и добавьте файл tor-alza.json, чтобы автоматически активировать ключ через вебхук и документировать требуемые параметры.

    {
  "key": "tor-alza...",
  "activation": "github",
  "repo": "username/project",
  "path": "scripts/delta.lua"
}

    Что добавить в ваш скрипт Delta

    1. Запрос ключа у пользователя

    При первом запуске предложите ввести ключ, полученный на сайте TorAlza. Сохраните его локально, чтобы не спрашивать повторно.

    2. Проверка через TorAlza API

    Используйте HTTP-запрос к https://api.tor-alza.dev/v1/keys/verify, чтобы убедиться, что ключ активен и привязан к вашему репозиторию.

    3. Обработка ошибок

    Если ключ невалиден или истёк, заблокируйте доступ к функционалу и покажите пользователю инструкцию о том, где получить новый ключ.

    -- Пример проверки ключа в Delta (Lua)
local http = game:GetService("HttpService")
local key = getgenv().TORALZA_KEY or ""

if key == "" then
    error("TorAlza: ключ не найден. Получите его на tor-alza.dev")
end

local response = http:PostAsync(
    "https://api.tor-alza.dev/v1/keys/verify",
    http:JSONEncode({ key = key, resource = "github:username/project" }),
    Enum.HttpContentType.ApplicationJson
)

local data = http:JSONDecode(response)
if not data.valid then
    error("TorAlza: ключ не прошёл проверку")
end
    1. Сохраните ключ в getgenv().TORALZA_KEY или аналогичном контейнере.
    2. Обновляйте параметр resource, чтобы он соответствовал вашему репозиторию или имени скрипта.
    3. Добавьте логирование в Discord/Analytics, чтобы отслеживать активации.

    Как это работает

    Простая архитектура, которую легко расширить под ваши процессы публикации скриптов Delta.

    1

    Регистрация скрипта

    Заполните форму публикации выше, чтобы связать репозиторий, вебхук и тестовый ключ. После подтверждения скрипт появится в кабинете разработчика.

    2

    Создание ключа

    Генерируйте ключи вручную через интерфейс или автоматически через API. Храните их в секции секретов репозитория и передавайте пользователям после покупки или подписки.

    3

    Активация

    При обращении к скрипту платформа сверяет ключ, фиксирует активацию и выдаёт статус. История доступна в личном кабинете разработчика, а пользователи получают мгновенную обратную связь.
