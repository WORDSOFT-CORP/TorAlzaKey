Генерация ключей

Создавайте ключи в формате tor-alzaXXXXXXXXXXXX с мгновенной копией в буфер обмена.

История текущей сессии

    Проверка ключей

    Вставьте ключ, чтобы убедиться, что он соответствует стандарту Tor Alza и готов к публикации.

    Платформа для разработчиков

    Создано для команд, которые хотят автоматизировать выдачу ключей и привязку их к релизам.

    CI/CD интеграция

    Подключите генерацию ключей в GitHub Actions или другом CI. Используйте CLI-сниппет ниже, чтобы выпускать ключ при каждом релизе.

    curl -sSL https://tor-alza.dev/cli | bash
export TOR_ALZA_TOKEN=<secret>
tor-alza key create --notes "Release $GITHUB_REF"

    API для проверки

    Стандартизированное REST API позволяет проверить ключ перед активацией скрипта. Используйте /v1/keys/verify с вашим секретом.

    POST https://api.tor-alza.dev/v1/keys/verify
Authorization: Bearer <secret>
{
  "key": "tor-alzaSk3isJ3ns92nzkE2jaE2ndO",
  "resource": "github:username/project"
}

    Проверка скриптов

    Разместите скрипт в GitHub и добавьте файл tor-alza.json, чтобы автоматически активировать ключ через вебхук.

    {
  "key": "tor-alza...",
  "activation": "github",
  "repo": "username/project",
  "path": "scripts/delta.lua"
}

    Как это работает

    Простая архитектура, которую легко расширить под ваши процессы.

    1

    Создание ключа

    Генерируйте ключи вручную через интерфейс или автоматически через API. Каждому ключу можно задать метаданные и срок действия.

    2

    Публикация скрипта

    Загрузите скрипт в GitHub и добавьте конфигурацию для проверки ключей. Платформа сама подписывает релизы и проверяет соответствие.

    3

    Активация

    При обращении к скрипту платформа сверяет ключ, фиксирует активацию и выдаёт статус. История доступна в личном кабинете разработчика.
